# 🎯 Random Name Picker

> A sleek, interactive, and customizable web application built to make choosing names, running raffles, and selecting winners fast, fair, and fun!

---

## ✨ Features

* 🎲 **Random Winner Selection** — Uses a smooth spinning animation to pick a unique winner from your list.
* 📝 **Smart Duplicate Handling** — Automatically filters out blank spaces and duplicate entries so every name gets a fair shot.
* ⏱️ **Built-in Countdown Timer** — Set custom time limits for timed events, games, or quick decisions.
* 🎵 **Background Music Toggle** — Optional soundtrack support to build anticipation before the big reveal.
* 🎉 **Confetti Winner Celebration** — Triggers a festive burst of confetti every time a winner is chosen.
* 📊 **Live Tracking & History** — View remaining available names alongside a dynamic log of all previously picked winners.
* 📱 **Fully Responsive Design** — Styled with **Tailwind CSS** for a clean, modern look across desktop, tablet, and mobile screens.

---

## 🛠️ Built With

* 🌐 **HTML5** — Semantic structure & layout
* 🎨 **Tailwind CSS & Custom CSS** — Modern styling & animations
* ⚡ **JavaScript (ES6+)** — Application logic & DOM manipulation
* 🎊 **Canvas Confetti Library** — Lightweight celebratory particle effects
